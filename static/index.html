help


    

      Type a formula (x, y) => z in the box at the top and press
      update formula (Enter). The surface is triangulated and
      rendered as hidden-line-eliminated SVG. The current formula is stored in
      the URL hash, so the address bar is a shareable link.
    


    
keyboard

    

      Click the canvas once so it has focus. Keys are captured there until you
      focus the formula box again. An uppercase letter (or the shifted symbol)
      repeats the action ten times.

mouse & touch

    
    
      
  • drag with the pointer (mouse or one finger) to pan the view.
    • 
      
  • scroll the wheel to zoom in and out, centred on the cursor.
    • 
    


    
inspect with devtools (F12)

    
    
      
  • 
        The drawing is a real SVG element in the DOM. Its <g fill="none">
        group contains one <path> per grayscale shade; each path's
        d attribute holds the M/L commands in
        scaled integer coordinates.
      
    • 
      
  • 
        The viewBox attribute on the <svg> is the
        camera framing. Edit it live in the inspector to pan and zoom by hand.
      
    • 
      
  • 
        The formula in the URL hash can be edited or shared; reloading the page
        re-evaluates it.
